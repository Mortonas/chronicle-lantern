# Contribution Policy

Chronicle Lantern is a public-source portfolio preview maintained from a separate private development repository. Outside code contributions, pull requests, feature requests, translations, and content submissions are not accepted for this release.

Please do not open an issue or discussion containing campaign notes, configuration values, provider details, credentials, local paths, or other private material. Issues, Discussions, Wiki, and Projects are intentionally disabled.

If you believe you have found a security vulnerability, follow [SECURITY.md](SECURITY.md). That document describes the confidential reporting route and the information that should be omitted from a report.
