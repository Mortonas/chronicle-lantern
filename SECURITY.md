# Security

Chronicle Lantern is a preview desktop application. Do not include credentials, vault paths, campaign material, provider prompts or responses, configuration values, or cache data in a public report.

Until a private reporting channel is listed in a cleared release, contact the repository owner through an existing private channel. Include only the minimum reproduction information and use synthetic data.

The project does not promise security-update support for this preview. Provider calls are user-initiated and are disabled in setup mode.
